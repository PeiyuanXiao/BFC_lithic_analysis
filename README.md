### 📝 Abstract

Growing fossil and genomic evidence has substantially advanced our understanding of Denisovans evolutionary history, yet their technological behaviours and subsistence strategies remain poorly documented. Here we present a comprehensive analysis of hominin fossils and associated archaeological remains from the Bianfu Cave, Yunnan Province, southwestern China. The hominin fossils are dated to \~167–134 thousand years ago (ka), while the cultural sequence spanned from \~190 ka to \~70 ka, representing one of the longest cultural records most parsimoniously attributed to Denisovans—identified through enamel-dentine junction morphology and palaeoproteomic analyses. The new fossils include four teeth that expand the known dental variation of this group, two cranial fragments, and a radius. Faunal and pollen records indicate a conifer-dominated forest or forest-steppe environment across Marine Isotope Stages 6 to 4. The inhabitants of Bianfu Cave practised specialised hunting of medium- to large-bodied prey and employed a technological strategy characterised by expedient core reduction and tool production, alongside pervasive use of unmodified bones. This pattern suggests an adaptive system prioritising the exploitation of object affordance over intensive tool manufacture. Bianfu Cave provides unprecedented insights into Denisovan biology, behaviour, and ecology in eastern Asia, and points to a substantial genetic and cultural legacy in later populations in Southeast Asia and Oceania.

```         
├── BFC_lithic_analysis.Rproj     # RStudio project file

├── BFC_lithic_data.xlsx          # Lithic assemblage data

├── renv.lock                     # Reproducible package environment

```

### 🚀 Reproduce the Analysis

``` r
# 1. Clone the repository
# git clone https://github.com/PeiyuanXiao/BFC_lithic_analysis.git

# 2. Open BFC_lithic_analysis.Rproj in RStudio

# 3. Restore the package environment
renv::restore()

# 4. Render the full analysis
quarto::quarto_render("BFC_lithic_analysis.qmd")
```

The rendered HTML report (`BFC_lithic_analysis.html`) contains all figures, tables, and statistical results.
